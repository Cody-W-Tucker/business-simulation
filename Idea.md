# Idea

## Main Priorities

- Browser interaction
- Movement
- Rooms

## Overview

Essentially, we're making a three-dimensional office to interact with different business systems.

## Browser Interaction

There will be different forms of interaction with primarily a browser interface that appear in-world like a large whiteboard, but when interacted with, open the specified URLs and it keeps that page up across reboots. So you set it once and then it's locked in. They could be editable over time, but that's one main interaction.

## Voice Interaction

We're also going to have a voice interaction so that you can talk to AI agents in the world. They will be a character model and we'll use something like a pipette voice SDK for C++. Maybe we'll use something like that or roll our own similar so that we stick with C Sharp. I don't know if we can use that. They have it maybe for Unity, but we're on Godot.

## Movement and Offices

But that's the main loop. We can move about the world. There may be different offices in different parts of the town that represent different customers or different businesses that we interact with. And that is the game loop.

## In-World Editing

There's also one kind of fun way of getting nitty-gritty. So all of these things will be editable by talking to the AI agent that's building this. But there might be some in-world editable things.

And I think to do that, there might be like little secret areas like the back rooms of the Matrix that you can either access with specific doors and passcodes. Or you shrink down to a very small size to go into this editable space.
