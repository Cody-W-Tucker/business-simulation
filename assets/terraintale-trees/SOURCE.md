# TerrainTale trees

Oak Tree Large, Ash Tree, and Pine Tree from TerrainTale's Realistic Surfaces &
Structure collection, downloaded 2026-11-01. TerrainTale identifies these as
CC0 1.0 assets, using ambientCG materials and trees grown with ez-tree by Daniel
Greenheck (MIT). The embedded WebP images were converted to PNG and the default
scene was set to scene 0 for Godot compatibility; geometry is unchanged.

- https://terraintale.com/library/realistic-surfaces/oak-tree-large
- https://terraintale.com/library/realistic-surfaces/ash-tree
- https://terraintale.com/library/realistic-surfaces/pine-tree
